    How the system works

    Detect

    IR or ultrasonic sensors report slot status.

    Allocate

    The nearest free slot is assigned.

    Park

    The vehicle enters and the timer starts.

    Bill and pay

    The fee is computed and paid digitally.

    Implementation

    Hardware
    ESP32, IR / ultrasonic sensors

    Database
